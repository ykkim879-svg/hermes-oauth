Privacy Policy

Last updated: 2026-11-26

This application ("hermes") is a personal-use tool operated by a single individual for managing their own Google account data. It is not a public service and has no users other than its owner.

1. Data accessed

The application accesses Google account data belonging to its owner only: Gmail messages, Google Drive files, Google Calendar events, Google Sheets and Docs, and Google Contacts.

2. How data is used

Data is used exclusively to perform tasks requested by the account owner on their own machine — reading email, updating personal spreadsheets, recording calendar entries, and similar personal record-keeping. No automated profiling, advertising, or analytics is performed.

3. Data storage

Data is not stored on any server. Access and refresh tokens are stored locally on the owner's own computer. No copy of Google account data is transmitted to any third party.

4. Data sharing

No data is sold, rented, shared, or disclosed to any third party. No data is used to train machine learning models. Data is not used for advertising purposes.

5. Third-party services

The application may call public financial data APIs (for stock prices) and AI model APIs (for text generation). These calls do not include Google account data.

6. Data retention and deletion

Since no data is stored externally, uninstalling the application or deleting its local token file ends all data access immediately. The owner may also revoke access at any time via Google Account Permissions.

7. Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Children's privacy

This application is not directed to anyone under 13 and collects no data from children.

9. Changes

Any changes to this policy will be posted on this page.
